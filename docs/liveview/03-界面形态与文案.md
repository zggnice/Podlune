# 界面形态与文案（实况窗三态）

## 一、状态栏胶囊

| 场景 | 胶囊内容 | 说明 |
|---|---|---|
| 睡眠定时 · 运行中 | 🕒 23:15 | 图标 + 剩余时间，纯文本无按钮 |
| 睡眠定时 · 渐弱中 | 🕒 00:28 渐弱 | 剩余 < 30 秒时追加状态词 |
| 下载 · 进行中 | ⬇ 42% | 百分比；多任务时显示总进度 |
| 下载 · 完成 | ✓ 完成 | 完成后停留 10 秒 |

## 二、锁屏卡片 / 通知中心卡片

### 睡眠定时

```
┌──────────────────────────────────────┐
│ 🕒  睡眠定时                   23:15 │
│     回放｜成蕾：央视主播、泄露机密… │
│     ──────────────────────  渐弱 30s │
│  [ +5 分钟 ]  [ 暂停定时 ]  [ 结束 ] │
└──────────────────────────────────────┘
```

- 主标题：`睡眠定时`
- 副标题：当前单集标题（超长省略）
- 进度：环形或线性倒计时（可选）
- 按钮：`+5 分钟` / `暂停定时` / `结束`

### 下载 / 备份

```
┌──────────────────────────────────────┐
│ ⬇  正在下载 3/8              42%     │
│     外刊精讲｜中国短剧杀进好莱坞…    │
│     ▓▓▓▓▓▓▓▓░░░░░░░░░░  约 2 分钟   │
│  [ 暂停 ]  [ 查看 ]                  │
└──────────────────────────────────────┘
```

- 主标题：`正在下载 3/8` / `备份导出 42%`
- 副标题：当前任务名
- 进度条：百分比 + 预计剩余
- 按钮：`暂停` / `查看`；失败态换成 `重试` / `查看`

## 三、交互与跳转

| 操作 | 行为 |
|---|---|
| 点击胶囊 / 卡片主体 | 打开应用 → 播放器页（睡眠定时场景自动展开定时面板） |
| 点击「+5 分钟」 | 剩余时间 +5 分钟，卡片文案立即刷新 |
| 点击「暂停定时」 | 结束本次定时（不暂停播放），实况窗关闭 |
| 点击「结束」 | 停止播放并结束定时，实况窗关闭 |
| 点击「查看」（下载） | 打开应用 → 下载管理页 |
| 点击「重试」 | 重新入队失败的下载任务 |

## 四、视觉与尺寸

- 圆角、内边距、字体层级遵循实况窗设计规范（胶囊高度 24vp 文本基线与系统状态栏对齐）。
- 深色/浅色分别给色值；强调色使用品牌紫 `#7C4DFF`（与 App 主色一致）。
- 图标使用系统符号（沙漏 / 下载箭头 / 对勾），避免自绘位图。
